Project Overview
This project provides a comprehensive analysis of Python as open-source software. It is divided into both theoretical evaluations and practical implementations:

Studying the origins and foundational philosophy of Python.

Analyzing its specific open-source licensing model.

Understanding its integration and role within Linux operating systems.

Exploring the broader open-source ecosystem.

Comparing Python against proprietary software alternatives.

Implementing shell scripts to demonstrate core Linux administrative concepts.

Shell Scripts Description

Script 1 — System Identity Report: Retrieves and displays fundamental system metrics, including the kernel version, active user, system uptime, current date, and Linux distribution details.

Script 2 — FOSS Package Inspector: Verifies the installation status of Python on the host system, outputting package details and a brief philosophical description utilizing a case statement.

Script 3 — Disk and Permission Auditor: Scans critical system directories to extract and report their respective sizes, access permissions, ownership, and group affiliations.

Script 4 — Log File Analyzer: Parses a specified log file to count the frequency of a target keyword (defaulting to "error") and outputs the most recent matching lines.

Script 5 — Open Source Manifesto Generator: Prompts the user for interactive input to dynamically generate a personalized open-source manifesto, saving the output as a distinct text file.
